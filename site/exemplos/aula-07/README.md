# Aula 07 — Box Model e Flexbox

O projeto possui 20 cartões para observar content, padding, border e margin. Os experimentos Flexbox demonstram direção, alinhamento, distribuição, quebra, ordem, crescimento, redução e espaçamento.

A interpretação da atividade é de pelo menos 20 declarações CSS relacionadas ao Flexbox em contêineres/itens diferentes. O material de aula lista exemplos principais, não vinte nomes distintos de propriedades.

A Atividade 01 do PDF é um formulário de grupo; preencha apenas com os dados verdadeiros dos participantes e anexe a captura de tela no Canvas.
