# Aula 08 — JavaScript: Sintaxe, Variáveis e Estruturas

## Objetivo da aula

Usar sintaxe básica de JavaScript, variáveis, operadores, condicionais, repetições, funções, arrays e objetos para acrescentar comportamento à página e manipular o DOM.

## Conteúdo abordado

- JavaScript executado no navegador.
- Inclusão de JavaScript em linha ou por arquivo externo.
- `var`, `let` e `const`; escopo e case sensitivity.
- Tipos: string, number, boolean, undefined, null, object, array, symbol e bigint.
- Operadores aritméticos, de comparação, lógicos e de atribuição.
- Condicionais `if`, `else if`, `else` e operador ternário.
- Repetições `for`, `while` e `do...while`, além de `break` e `continue`.
- Funções tradicionais e arrow functions.
- Arrays, `forEach` e `filter`.
- Objetos, propriedades, métodos e `this`.
- DOM, seletores, `textContent`, `value`, `classList`, `createElement`, `appendChild` e `addEventListener`.

## Atividade indicada no PDF

Criar um projeto com `index.html`, `style.css` e `script.js` usando JavaScript externo; implementar pelo menos cinco funcionalidades conforme os exemplos da aula; incluir `README.md` com pelo menos 100 linhas; versionar e publicar no GitHub; realizar melhorias para ter mais de 500 linhas de HTML, mais de 400 linhas de CSS e mais de 300 linhas de JavaScript; comentar todo o código, documentar o repositório com prints e enviar no Canvas.

## Resolução

O projeto em `exemplos/aula-08/` é um painel acadêmico interativo com seis funcionalidades:

1. Saudação personalizada por nome.
2. Contador com incremento e decremento.
3. Calculadora de média com array de notas e classificação condicional.
4. Lista de tarefas criada dinamicamente com `createElement` e `appendChild`.
5. Filtro de conteúdos por categoria usando `filter` e `forEach`.
6. Alternância de tema com `classList.toggle`.

Os arquivos estão separados: HTML em `index.html`, CSS em `style.css` e lógica em `script.js`. O `README.md` do próprio exemplo documenta os recursos e os passos para testar.

## Por que seis funcionalidades?

O requisito é “pelo menos cinco”. A sexta foi incluída para cobrir mais de um mecanismo de manipulação do DOM sem depender de frameworks ou bibliotecas externas.

## Resultado esperado

Uma página em que o usuário consegue interagir com os componentes e observar alterações reais no DOM. O console do navegador também pode ser usado para acompanhar mensagens e depurar erros.

## Conceitos-chave

Variáveis, tipos, operadores, condicionais, loops, funções, arrays, objetos, DOM, eventos e manipulação de conteúdo.
