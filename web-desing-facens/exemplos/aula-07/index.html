3. Layout responsivo

Redimensione a janela do navegador. Os cartões devem quebrar a linha e ocupar a largura disponível.

  • Use uma largura máxima para evitar conteúdo muito esticado.
  • Permita que os itens Flexbox quebrem linha com flex-wrap.
  • Use media queries quando a organização precisar mudar por faixa de largura.

4. Quadro de referência do Box Model

Este quadro resume propriedades relacionadas às caixas e ajuda a revisar os vinte cartões demonstrativos acima.

ElementoPropriedadeFunção
Cartão 01contentÁrea em que o texto ou a mídia é exibida.
Cartão 02paddingEspaço interno entre conteúdo e borda.
Cartão 03borderContorno que envolve o padding e o conteúdo.
Cartão 04marginEspaço externo que separa caixas vizinhas.
Cartão 05box-sizingDefine como largura e altura são calculadas.
Cartão 06widthLargura declarada da caixa.
Cartão 07max-widthLimite superior para a largura.
Cartão 08min-widthLimite inferior para a largura.
Cartão 09heightAltura declarada da caixa.
Cartão 10min-heightAltura mínima para acomodar conteúdo.
Cartão 11border-radiusArredondamento dos cantos da borda.
Cartão 12border-styleEstilo visual do contorno.
Cartão 13border-widthEspessura do contorno.
Cartão 14border-colorCor do contorno.
Cartão 15padding-blockEspaçamento interno no eixo vertical.
Cartão 16padding-inlineEspaçamento interno no eixo horizontal.
Cartão 17margin-blockMargem externa no eixo vertical.
Cartão 18margin-inlineMargem externa no eixo horizontal.
Cartão 19overflowControle do conteúdo que excede a caixa.
Cartão 20outlineContorno auxiliar, diferente da borda.

Altere os valores no arquivo CSS e observe qual parte da caixa muda. Para uma comparação justa, mantenha o mesmo conteúdo e modifique uma propriedade por vez.
