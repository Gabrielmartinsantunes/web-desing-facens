    Biblioteca de conceitos

    Referência rápida de JavaScript

    Este catálogo estático revisa os assuntos que aparecem no material da aula.

    01

    Variáveis

    Use const quando a referência não será reatribuída e let quando o valor puder mudar.

    02

    Escopo

    let e const respeitam o bloco; var tem escopo de função.

    03

    Tipos de dados

    String, number, boolean, undefined, null, object e array aparecem em programas.

    04

    Case sensitive

    nome, Nome e NOME são identificadores diferentes.

    05

    Aritmética

    +, -, *, /, %, **, ++ e -- fazem operações numéricas.

    06

    Comparação

    === compara valor e tipo; !== verifica diferença estrita.

    07

    Lógica

    &&, || e ! combinam ou invertem condições booleanas.

    08

    Atribuição

    =, +=, -=, *= e /= atualizam o valor de uma variável.

    09

    Condicionais

    if, else if e else selecionam caminhos conforme uma condição.

    10

    Ternário

    Uma expressão condicional pode escolher entre dois valores.

    11

    for

    Use for quando o número ou o intervalo de repetições é conhecido.

    12

    while

    Repete o bloco enquanto a condição for verdadeira.

    13

    do...while

    Executa o bloco uma vez antes de avaliar a condição.

    14

    break

    Interrompe um laço antes de terminar suas repetições.

    15

    continue

    Pula o restante da iteração atual e segue para a próxima.

    16

    Funções

    Funções agrupam instruções reutilizáveis e podem receber parâmetros.

    17

    return

    Devolve um resultado da função para quem a chamou.

    18

    Arrow functions

    A sintaxe const nome = () => {} cria uma função de seta.

    19

    Arrays

    Arrays guardam uma sequência de valores acessados por índice.

    20

    length

    A propriedade length informa quantos elementos existem no array.

    21

    forEach

    Percorre cada item do array para executar uma função.

    22

    filter

    Cria um novo array com os itens que atendem a uma condição.

    23

    Objetos

    Objetos agrupam propriedades e métodos relacionados.

    24

    this

    Dentro de um método, this pode referenciar o próprio objeto.

    25

    DOM

    O DOM representa a estrutura da página como uma árvore de nós.

    26

    querySelector

    Seleciona o primeiro elemento que corresponde a um seletor CSS.

    27

    getElementById

    Seleciona um elemento pelo seu identificador.

    28

    textContent

    Lê ou altera o texto de um elemento sem interpretar HTML.

    29

    value

    Lê ou altera o valor atual de um campo de formulário.

    30

    classList

    Permite adicionar, remover ou alternar classes CSS.

    31

    createElement

    Cria um novo elemento HTML no documento.

    32

    appendChild

    Adiciona um nó como filho de outro elemento.

    33

    addEventListener

    Registra uma função para responder a um evento.

    34

    click

    O evento de clique permite reagir à ativação de um botão.

    35

    input

    O evento input ocorre quando o valor de um campo é alterado.

    36

    console.log

    Exibe informações no console para ajudar na depuração.

    37

    alert e prompt

    São formas simples de interação apresentadas nos exemplos básicos.

    38

    Validação

    Antes de calcular, confira se os campos contêm valores válidos.

    39

    Reutilização

    Extraia tarefas repetidas para funções com nomes descritivos.

    40

    Leitura de código

    Use nomes claros e comentários para explicar decisões importantes.

    Caderno complementar de sintaxe

    Os cartões a seguir reforçam exemplos curtos dos assuntos trabalhados nos slides. Teste cada trecho no console do navegador ou em um arquivo JavaScript separado.

    41

    Declaração const

    const curso = "Web Design";

    Use const quando a referência não precisar ser reatribuída.

    42

    Declaração let

    let tentativas = 0;

    Use let quando o valor for atualizado durante a execução.

    43

    Template string

    const frase = `Olá, ${nome}!`;

    Interpolação deixa a montagem de textos mais legível.

    44

    Conversão numérica

    const nota = Number("8.5");

    Converta entradas de texto antes de operações matemáticas.

    45

    Verificação NaN

    Number.isNaN(nota);

    Verifique se uma conversão resultou em um valor numérico inválido.

    46

    Operador resto

    const resto = 10 % 3;

    O operador % retorna o resto de uma divisão.

    47

    Comparação estrita

    10 === "10";

    A comparação estrita também considera o tipo do valor.

    48

    Operador lógico

    idade >= 18 && possuiDocumento

    && exige que as duas condições sejam verdadeiras.

    49

    Operador OR

    temCupom || compraMaiorQueCem

    || aceita que pelo menos uma condição seja verdadeira.

    50

    Operador ternário

    const status = ativo ? "Ativo" : "Inativo";

    O ternário escolhe entre dois valores com base em uma condição.

    51

    Switch

    switch (opcao) { case 1: break; default: break; }

    switch organiza decisões baseadas em valores específicos.

    52

    Laço for

    for (let i = 0; i < 3; i++) { console.log(i); }

    for é útil quando a repetição possui um contador.

    53

    Laço while

    while (contador < 3) { contador++; }

    while repete enquanto a condição permanecer verdadeira.

    54

    Laço do while

    do { contador++; } while (contador < 3);

    do while executa o bloco ao menos uma vez.

    55

    Break

    if (valor < 0) break;

    break encerra o laço mais próximo.

    56

    Continue

    if (valor === 0) continue;

    continue pula para a próxima iteração.

    57

    Função declarada

    function somar(a, b) { return a + b; }

    Funções agrupam instruções e podem devolver um resultado.

    58

    Arrow function

    const dobrar = numero => numero * 2;

    Arrow functions oferecem uma sintaxe compacta.

    59

    Parâmetro padrão

    function saudar(nome = "visitante") { return nome; }

    Parâmetros padrão cobrem chamadas sem argumento.

    60

    Array literal

    const cores = ["azul", "verde", "ocre"];

    Arrays armazenam sequências ordenadas.

    61

    Acesso por índice

    const primeiraCor = cores[0];

    O primeiro elemento de um array ocupa o índice zero.

    62

    Método push

    cores.push("cinza");

    push adiciona um elemento ao final do array.

    63

    Método map

    const tamanhos = [1, 2, 3].map(n => n * 2);

    map cria um novo array a partir da transformação dos itens.

    64

    Método filter

    const aprovadas = notas.filter(n => n >= 6);

    filter mantém os itens que passam em uma condição.

    65

    Objeto literal

    const aluno = { nome: "Ana", aprovado: true };

    Objetos agrupam propriedades relacionadas.

    66

    Acesso a propriedade

    aluno.nome;

    A notação de ponto acessa uma propriedade pelo nome.

    67

    Desestruturação

    const { nome } = aluno;

    A desestruturação extrai propriedades para variáveis.

    68

    Query selector

    document.querySelector(".mensagem");

    querySelector retorna o primeiro elemento que corresponde ao seletor.

    69

    Alterar texto

    elemento.textContent = "Atualizado";

    textContent altera o texto sem interpretar HTML.

    70

    Classe CSS

    elemento.classList.add("destaque");

    classList permite adicionar, remover e alternar classes.
