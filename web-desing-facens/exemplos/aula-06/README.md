# Aula 06 — Projeto CSS básico

Abra `index.html` no navegador. O CSS foi vinculado por meio da tag `link` e fica em `style.css`. O exemplo foi dimensionado para ultrapassar 300 linhas de HTML e 200 linhas de CSS, como solicita o enunciado.

Propriedades principais usadas: color, background-color, font-family, font-size, margin, padding, border, width, height, display, position, top, text-align, além de max-width, min-height, line-height, letter-spacing, border-radius, box-shadow, transition, transform, opacity, gap, flex-wrap, overflow, object-fit, aspect-ratio, z-index e outline.
