Revisão

Roteiro de inspeção do CSS

Use estes pontos para verificar o comportamento do layout depois de alterar as regras.

Checklist de propriedades e decisões

  • Confira se o seletor corresponde ao elemento esperado.
  • Observe a especificidade quando duas regras entram em conflito.
  • Verifique se a cor do texto mantém contraste suficiente.
  • Compare a família tipográfica com a finalidade da interface.
  • Use tamanho de fonte legível em telas pequenas.
  • Revise a margem externa para evitar espaços acumulados.
  • Revise o padding para afastar conteúdo das bordas.
  • Confira a espessura e a cor das bordas.
  • Evite larguras fixas que provoquem rolagem horizontal.
  • Use altura mínima quando o conteúdo puder variar.
  • Escolha display de acordo com o tipo de organização desejado.
  • Use position somente quando houver necessidade de posicionamento.
  • Teste top, right, bottom e left em elementos posicionados.
  • Observe o alinhamento de texto em parágrafos longos.
  • Verifique os estados de hover e focus dos links.
  • Redimensione a janela e teste a quebra dos cartões.
  • Evite depender exclusivamente de cor para comunicar estados.
  • Confirme se a folha externa foi carregada pelo navegador.
  • Remova regras duplicadas que não tenham justificativa.
  • Comente decisões que não sejam evidentes pelo próprio código.
