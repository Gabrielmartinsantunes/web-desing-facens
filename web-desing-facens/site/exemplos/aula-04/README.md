# Aula 04 — Mídias em HTML

Abra `index.html` no navegador. Três imagens em SVG acompanham o exemplo. O PDF original menciona `video.mp4`, `musica.mp3` e `musica.ogg`, mas não disponibiliza os binários; portanto, crie as pastas e coloque os arquivos nesses caminhos para testar reprodução.

A atividade usa formulário de demonstração sem backend. Ele valida os campos obrigatórios no navegador, mas não armazena nem transmite a mensagem.
