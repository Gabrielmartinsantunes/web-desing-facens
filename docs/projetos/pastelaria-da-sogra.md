# Projeto de referência — Pastelaria da Sogra

O projeto [Pastelaria da Sogra](https://github.com/vitorhugo-santos/projeto-web-pastelaria-da-sogra) é citado nesta apostila como trabalho acadêmico desenvolvido em grupo. A referência é usada para conectar os conceitos de Web Design a um projeto concreto, sem atribuir autoria individual exclusiva.

## O que observar ao estudar o projeto

- Estrutura de páginas HTML e navegação entre seções.
- Separação de arquivos de CSS e JavaScript.
- Organização de imagens e demais recursos.
- Uso de formulários, filtros e componentes interativos.
- Histórico de alterações no Git e documentação do projeto.
- Limites explicitados no próprio README, como funcionalidades de demonstração que não processam pedidos ou pagamentos reais.

## Como relacionar com as aulas

| Conteúdo da apostila | O que observar no projeto |
|---|---|
| HTML e semântica | Estrutura das páginas, cabeçalhos, seções, links e formulários |
| Mídias em HTML | Imagens e elementos visuais do site |
| SEO | Títulos, descrições, estrutura e atributos de imagens, quando presentes |
| CSS | Organização visual, seletores, tipografia e responsividade |
| Box Model e Flexbox | Espaçamentos, cartões, menus e alinhamento dos elementos |
| JavaScript | Filtros, carrinho demonstrativo, interações e atualização de conteúdo |
| Git | Commits, organização do repositório e colaboração |

## Cuidados ao apresentar

1. Identifique o trabalho como projeto em grupo.
2. Não copie o código sem compreender o que cada parte faz.
3. Diferencie funcionalidades de demonstração das operações reais. O README do projeto informa que o site é acadêmico, não recebe pedidos reais e não processa pagamentos.
4. Use o repositório original como fonte primária para detalhes e versões atualizadas.
