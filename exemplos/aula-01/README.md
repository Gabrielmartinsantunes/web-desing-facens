# Site complementar — Aula 01

Este é um site demonstrativo independente para a apresentação da disciplina. Resume a visão geral de Web Design, os formatos de avaliação descritos nos slides e o procedimento da primeira atividade.

**Atenção:** o PDF da Aula 01 não propõe um exercício de programação. A atividade solicitada é formar um grupo de 3 a 5 integrantes e enviar os nomes completos na atividade indicada no Canvas. Este site é um material de apoio criado para tornar as informações navegáveis; não é uma atividade oficial nem um formulário de entrega.

## Arquivos

- `index.html`: conteúdo e estrutura semântica.
- `style.css`: identidade visual e layout responsivo.
- `script.js`: verificador demonstrativo da quantidade de integrantes.

## Como testar

Abra `index.html` em um navegador. Na seção “Organize seu grupo”, use os botões ou o campo numérico para conferir se a quantidade informada está entre 3 e 5. O checklist não salva dados e não envia informações ao Canvas.
